> first of all the problem is actually in the Ip Address. We used the `127.0.0.1 to connect to the docker world. but that is the problem. because docker is a VM this address means diffrent than our computer.  the IP refers to the container’s loopback interface, not the host machine’s. Threfore it will gonna give back an error of

```sh
    Traceback (most recent call last):
  File "/code/Simple_Server.py", line 124, in <module>
    start_server()
  File "/code/Simple_Server.py", line 21, in start_server
    server_socket.bind(('0.0.0.0', port))  # Bind to all interfaces
OSError: [Errno 98] Address in use
```

This problem has been solved as we use 0.0.0.0 for binding. This binds the server to all network interfaces within the container, allowing external access. Then we update the dockerfile that had port 5000. Since the server listens on port 8080, update EXPOSE to 8080.

Additionally we want to see the logs of our running server. to make that possible we add "-u" in the CMD line (see the dockerfile).
